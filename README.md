# Mounir Al Jurdi

I build web apps and Windows tools for small businesses. My recent work covers retail storefronts, print shop workflows, and interactive 3D on the web.

## Selected work

### [ROLX · Watch storefront](https://github.com/moner005/react-Store)

A team project for browsing watches by store branch, filtering the catalog, and trying a checkout flow. The React client uses a NestJS API backed by MongoDB for catalog data.

**React · TypeScript · NestJS · MongoDB**  
[Source and setup guide](https://github.com/moner005/react-Store#readme)

### Waraq · Print shop file desk

A Windows app that lets customers scan a QR code and send files from their phones over the shop's Wi-Fi. Staff can preview incoming files, track print jobs, and send scanned documents back to customers.

**Windows desktop · Local networking**

### AlBuraq Diamonds · Interactive 3D prototype

A WebGPU prototype for presenting diamonds and jewelry in the browser. It explores how lighting and motion can show a diamond's cut and brilliance.

**WebGPU · Real-time 3D**
